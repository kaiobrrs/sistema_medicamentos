
# Sistema de Gerenciamento de Medicamentos

## Sobre o projeto

Sistema desenvolvido em Python para gerenciamento de usuários, cadastro de medicamentos, organização de horários e notificações.

## Objetivo

Facilitar o controle e a organização dos medicamentos utilizados por diferentes usuários.

## Funcionalidades

- Cadastro de múltiplos usuários.
- Cadastro de medicamentos.
- Associação de medicamentos aos usuários.
- Agendamento de horários.
- Notificações automáticas.
- Histórico de administrações.

## Tecnologias

- Python
- Arquivos TXT
- Git
- GitHub

## Organização

- controllers: operações do sistema.
- models: estruturas e regras dos dados.
- utils: validações.
- database: armazenamento dos arquivos TXT.
- tests: testes automatizados.
